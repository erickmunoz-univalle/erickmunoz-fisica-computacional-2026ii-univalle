# Formula semiempírica de Masa atómica

En esta carpeta se encuentran los códigos, archivos y notebooks trabajados en **Google Colab** para el Taller 6 del curso de Física Computacional (Univalle 2026-2).

### Contenido
- `analisis_nucleo.py` $\rightarrow$ Módulo en Python para lectura, procesamiento y graficación de datos nucleares.
- `curva_enlace.png` Gráfica de la curva de máximo enlace.
- `diagrama_de_flujo.png` Diagrama lógico del algoritmo de búsqueda del programa principal.
- `maximo.dat` Resultado del núcleo más ligado de la curva generado en Fortran.
- `maximo_python.dat` Resultado del núcleo más ligado de la curva verificado en Python.
- `modulo_nucleo.f90` Módulo en Fortran con constantes y funciones de los términos semiempíricos.
- `nucleos.dat` Datos calculados de energía y masa para los ocho núclidos de referencia.
- `programa_nucleo.f90` Programa principal en Fortran para la simulación del valle de estabilidad.
- `taller6_colab.ipynb` Notebook principal con el entorno de ejecución integrado en Colab.
- `valle.dat` Datos de la curva de máximo enlace por nucleón.

Estos archivos muestran el proceso de programación, pruebas y resultados obtenidos durante el taller.
