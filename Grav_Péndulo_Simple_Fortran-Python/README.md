# Valor de g con datos de Péndulo Simple a través de Fortran y Python

En esta carpeta se encuentran los códigos, archivos y notebooks trabajados en **Google Colab** para el Taller 3 del curso de Física Computacional (Univalle 2026-2).

### Contenido
- `taller3_colab.ipynb` → Notebook principal con el desarrollo en Colab.
- `informe_limpieza.xlsx` → Informe de limpieza de los datos.
- `pendulo_limpio.dat` → Script de limpieza de los datos.
- `ajuste_pendulo.f90` → Programa en Fortran que ajusta los datos linealmente por mínimos cuadrados.
- `resultados_ajuste.dat` → Datos de resultados del ajuste lineal por mínimos cuadrados.
- `ajuste_pendulo_y_residuos.png` → Imágenes de las gráficas del ajuste del péndulo y residuos.
- `reporte_taller3.pdf` → Reporte principal del taller.

Estos archivos muestran el proceso de programación, pruebas y resultados obtenidos durante el taller.
